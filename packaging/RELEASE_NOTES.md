**Orbit 0.2.0: control Orbit with anything.**

Orbit started as a way to use the CMF Buds Pro 2 dial. Now almost any control can drive it.

**New**
- **Any controls.** Earbuds and headphones with buttons (AirPods, OnePlus, Galaxy, Pixel Buds…), wired earphones, Bluetooth speakers, keyboard volume knobs and media keys, any key or shortcut, mouse side buttons, Ctrl + scroll and trackpad gestures. On Android also the phone's volume keys, selfie sticks, remotes, keyboards, game pads, **back tap**, **chop** and **twist**.
- **Simple setup.** "What do you want to control Orbit with?" CMF Buds Pro 2, other earbuds, keys, mouse, trackpad… or set it up yourself. Run it again any time from Settings → Controls.
- **Setup controls.** Four functions: Open menu, Select, Previous, Next. Give each any trigger: **Choose** from a list, or **Record** by pressing it. Load presets, Reset, and add Previous tool or a custom shortcut (desktop).
- **Camera tool does video (Android).** Turn to switch Photo / Video, press to take a photo or start / stop recording.
- **Laptop brightness (Windows)** now changes the built-in screen.

**More reliable buttons**
- Keys are only taken over when one of your triggers uses them; everything else works as normal.
- A key bound only to "hold" still does its usual job on a quick tap (Volume + still turns the volume up).
- No more stuck keys after the screen turns off, the PC locks or sleeps, or a password field takes the keyboard.
- Windows: Bluetooth keyboard knobs work; Orbit recovers if Windows drops its keyboard hook; no stray Start menu after Win + key triggers.

**Notes**
- CMF Buds Pro 2: set the dial in Nothing X as before (single = Play/Pause, double = Next, triple = Previous, hold = Voice assistant).
- Windows' own 3- and 4-finger touchpad gestures still run; to use them for Orbit, set them to "Nothing" in Settings → Bluetooth & devices → Touchpad.
- Android: buttons are read while the screen is on.
- macOS: Apple Silicon only, not notarized (right-click → Open the first time).
